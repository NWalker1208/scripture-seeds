# Scripture Seeds

This project was last built using Flutter v3.41.9.

## Build (Android)

1. Create `android/key.properties` (https://docs.flutter.dev/deployment/android#reference-the-keystore-from-the-app)
2. Run `fvm install`
3. Run `fvm flutter pub get`
4. Run `fvm dart run flutter_launcher_icons`
5. Run `fvm flutter build appbundle`
